Do you need to accept anything?

Yes for one category. The two items marked Necessary below are used no matter what, since the site can't remember your theme or your cookie choice without them. The items marked Optional only run after you click Accept on the banner — if you click Decline, none of them run.

Cookies & browser storage used here

NameTypePurposeDurationCategory
theme First-party cookie Remembers whether you've chosen light or dark mode 1 year (only set once you use the toggle) Necessary
analytics-consent First-party cookie Remembers your Accept/Decline choice for analytics 1 year Necessary
visitorToken First-party session storage Anonymous ID that groups your page views within one visit Cleared when you close the tab Optional — only if Accepted

entryTime / lastPage First-party session storage Used to calculate session length and the path you took through the site Session only Optional — only if Accepted

Other requests that aren't cookies, but still involve a data transfer

These load automatically when a page opens — separately from the cookie banner above — because the page needs them to render maps or 3D graphics. They can see your IP address as a normal side effect of your browser fetching a file from their servers:

  • unpkg.com — delivers the Leaflet.js and Three.js code libraries
  • Esri / OpenStreetMap (arcgisonline.com) — supplies map tile images on the Visitors page
  • threejs.org — supplies the Earth texture image on the Atlas globe
  • raw.githubusercontent.com (GitHub) — supplies a country-boundary data file on the Visitors page
  • Cloudflare Worker (visitor-tracker.pavle-radojevic3.workers.dev) — the Visitors page requests its aggregate statistics from here every time it opens, whatever your cookie choice

None of these set cookies on this site, and none of them are used for analytics. This site's typefaces are hosted on the site itself, so no request is made to Google for them.
